ZNirmaan Portal architecture

A static web app. Everything runs in the browser; there is no backend.

Prototype, demo data

1 Sources

OpenStreetMap extract

Real building footprints near Shivaji Nagar metro station and the Purple Line alignment, saved in scripts/osm/.

Build time

Cesium ion

World Terrain for ground heights, OSM Buildings for the surrounding city, and aerial imagery.

Streamed while you use the map

Browser storage

Remembers the language and whether Tower 1 is registered, so a reload keeps the demo where it was. Read by every screen.

2 Demo data

Site data

site.generated.json: 15 plots with CTS numbers and ULPINs, the metro tunnels and the water main.

Tower 1

Built in code: 2 basements, ground floor, 8 floors and a terrace. Every flat, parking bay and common area as a 3D volume with its holder and rights.

32 flats 24 allotted 22 common

Underground lines

Two metro tunnels and a water main, each with a G-type 3D-ULPIN, and the restrictions on every plot above them.

3 Core logic

Plain TypeScript, unit tested

3D-ULPIN codes

Builds and reads PLOT-ULPIN-T B LL UUU C. The check character (ISO 7064 MOD 37,36) catches every single typo and nearly every swap.

Search lookup

Plot number, ULPIN or 3D-ULPIN; marks the wrong characters and suggests the right code.

Right of user geometry

The strip of each plot above a metro tube, as hatch lines draped on the ground.

English and Hindi

Every label, and record text such as names, places and deeds, in Devanagari.

Build and hosting

Vite builds a static site into dist/ with hash links, so any static host works. The Cesium token comes from .env.local and is never committed.

Checks

45 unit tests (codes, typo check, data, translations), 43 browser checks of every screen, and a timed demo rehearsal in both languages.

Stack

React, TypeScript, Vite, CesiumJS, react-router, i18next, qrcode, Fontsource fonts, Vitest and Playwright.
